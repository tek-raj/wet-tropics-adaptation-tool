PHOTOS FOR THE OVERVIEW PAGE

Until a photo is added, a drawn illustration from the app/illustrations folder is shown instead.
Put photos in this folder using the names below. Each one replaces its placeholder
automatically; just refresh the browser. Landscape photos work best (about 1600 x 900 pixels, JPG).

  hero.jpg                     Large banner at the top of the Overview page
  topic-climate-change.jpg     Card: What is climate change?
  topic-hazards.jpg            Card: What are climate hazards?
  topic-risk.jpg               Card: Risk, exposure, vulnerability and adaptive capacity
  topic-scenarios.jpg          Card: Climate scenarios
  topic-process.jpg            (spare, not currently shown)
  example-flying-fox.jpg       Worked example: spectacled flying-fox

To use different file names, change the "photos" list near the top of app/js/overview.js.
Only use photos you have permission to publish, and credit the photographer where required.
